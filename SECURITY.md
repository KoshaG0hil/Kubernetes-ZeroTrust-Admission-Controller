# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have discovered a security vulnerability or bypass in the zero-trust admission rules, please report it responsibly:

1. **Do not create a public GitHub Issue.**
2. Email details to **gohilkosha19@gmail.com** with the subject `[SECURITY VULNERABILITY] Kubernetes Zero-Trust Admission Controller`.
3. Include:
   - A description of the vulnerability and attack vector.
   - Steps to reproduce or a sample non-compliant Kubernetes manifest.
   - Impact assessment (e.g., privilege escalation, container escape, policy bypass).

You will receive an initial response within 48 hours acknowledging receipt, followed by a remediation plan and CVE attribution where applicable.
